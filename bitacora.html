· Bitácora de Desarrollo ·

Registro cronológico de reuniones, acuerdos, decisiones de diseño, retos técnicos y soluciones adoptadas durante el desarrollo de esta página Web.

Fase 1 · Planificación y Organización del Proyecto

1. Coordinación Inicial y Definición de Roles

Nos reunimos para leer detenidamente las consignas y requerimientos para la entrega del presente proyecto. Acordamos la división de tareas entre los integrantes
(a.k.a: Johi, Mariü, Migue, Sergio, Sony).
Creamos una nube compartida en Gmail y un repositorio público grupal en GitHub.

  • Decisiones: Establecer una guía de estilo compartida (CSS Variables) en css/styles.css para evitar discrepancias de color y tipografía entre las páginas.
  • Próximo Paso: Realizar un cuestionario para evaluar el contenido de los perfiles personales.
Fase 2 · Estructura, Maquetación HTML5 y Diseño Adaptativo

2. Estructura HTML, Semántica y Grid System

Se maquetaron las páginas principales: «portada» (index.html), «perfiles» individuales de los 5 integrantes y la «bitácora». Se utilizaron elementos semánticos (header, nav, main, article, aside, footer).

  • Breakpoints Obligatorios: Configuración estricta de Media Queries CSS para 400px, 900px y 1200px garantizando visualización fluída sin desbordes.
  • Decisión de Diseño: Logotipo del equipo DataHell (iniciado con moodboard en Canva y bocetos manuales, digitalizado iterativamente con Gemini e IA), colores representativos de la marca e imágenes de perfil con avatares ilustrados, generados en Gemini a partir de fotos reales mediante un prompt uniforme para mantener coherencia visual y resguardar la privacidad.
Fase 3 · Retos Técnicos y Ajustes

3. Dificultades Superadas durante el Desarrollo

Dificultad 1: Desbordes de texto y tarjetas en dispositivos móviles de 400px.
Solución: Implementación del menú desplegable "Hamburger" mediante JavaScript y ajuste de grid-template-columns: 1fr en pantallas pequeñas.

Dificultad 2: Mantener uniformidad sin restringir la personalidad de los perfiles individuales.
Solución: Uso de una tarjeta base común combinada con componentes dinámicos personalizados en JS.

  • Criterio sobre IA: El uso de Gemini y Antigravity aportó agilidad en la generación visual del logo y avatares, y en el cálculo de contrastes AAA, pero requirió estricto control humano.

Dificultad 3: Garantizar que el soporte asistivo de la IA no afectara la autoría ni la calidad técnica requerida.
Solución: Cada integrante redactó y curó sus propios contenidos personales, y el código (CSS, responsive y DOM) fue revisado, ajustado y depurado manualmente por el equipo para cumplir al 100% con los estándares de la consigna.

Fase 4 · Interactividad Dinámica con JavaScript

4. Implementación de Funciones Dinámicas

Se integró JavaScript nativo para añadir dinamismo en la «portada» (generador de frases inspiradoras y contadores animados) , en cada «perfil» (caja de reseña de películas/discos y envío de saludos) y en la presente «bitácora».

Fase 5 · Publicación en Vercel y Documentación

5. Publicación y Documentación Final en README

Se conectó el repositorio grupal de GitHub con la plataforma Vercel para el despliegue continuo en producción. Redacción final del archivo README.md cumpliendo exhaustivamente con todos los criterios y requerimientos de la consigna asignada para el presente proyecto.

Nuestro lema: Hacer que la tecnología de vanguardia sea accesible para tod@s, democratizando el acceso a soluciones de software que impulsan el progreso y la igualdad de oportunidades.
